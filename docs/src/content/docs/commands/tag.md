Manage git tags

## Usage

```bash
go-cli-package tag [list|create|delete]
```

## Flags




| Flag | Type | Description |
|------|------|-------------|
| --limit | int | Maximum number of tags to display (0 = all) |
| --force | bool | Delete and recreate the tag if it already exists |
