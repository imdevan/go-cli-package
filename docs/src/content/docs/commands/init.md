Initialize packaging repositories (Homebrew tap and/or AUR repository)

## Usage

```bash
go-cli-package init [homebrew|aur|all]
```

## Flags




| Flag | Type | Description |
|------|------|-------------|
| -f, --force | bool | Force reinitialization, overwriting existing directories |
