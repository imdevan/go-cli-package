Package and release helper CLI.

### Example

```bash
go-cli-package completion bash
```

## Usage

```bash
go-cli-package
```

## Flags




| Flag | Type | Description |
|------|------|-------------|
| -v, --version | bool | Print version and exit |


## Available Commands


- [`completion`](/commands/completion) - Generate shell completion scripts
